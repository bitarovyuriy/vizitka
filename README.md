# Визитка Юрия Битарова

Статичный сайт-портфолио: `index.html` + `style.css` + `script.js` + `videos.json`.
Хостинг — GitHub Pages: https://bitarovyuriy.github.io/vizitka/

## Как добавить или изменить проект

Все проекты лежат в `videos.json` — обычный список. Карусель первого экрана показывает
все горизонтальные проекты по кругу, в порядке файла. В сетке сначала идут избранные работы.

```json
{
  "id": 9,
  "short": "Forbes: короткое название для карточки",
  "title": "Полное название видео — показывается в модалке",
  "description": "Что именно делал (монтаж, цвет, графика)",
  "url": "https://www.youtube.com/embed/XXXXXXXXXXX",
  "thumbnail": "covers/имя-файла.avif",
  "platform": "youtube"
}
```

- `short` — короткое название карточки (максимум две строки), без него используется `title`.
- `description` — описание работы; используется как роль, если отдельное поле `role` не заполнено.
- `url` — готовая embed-ссылка или обычная страница YouTube/VK: скрипт нормализует адрес.
- `thumbnail` — файл из папки `covers/`, лучше 1280×720 (16:9).
- `platform` — `youtube`, `vk` или `vimeo`: от этого зависит маленькая иконка в углу обложки и параметры плеера.

## Избранные работы и подписи

В записи можно добавить три необязательных поля:

```json
{
  "client": "Forbes",
  "role": "Монтаж интервью и синхронизация дубляжа",
  "featured": true
}
```

- `client` — издание или проект: отдельная приглушённая строка под названием. Без поля строка отсутствует.
- `role` — выполненная работа: читаемая строка после издания, с переносами на десктопе.
  Если поле отсутствует или пустое, используется `description`.
- `featured: true` — большая карточка в начале сетки. Учитываются максимум две отмеченные
  горизонтальные записи в порядке файла. Если отметок нет, большими становятся первые две
  горизонтальные работы. Остальные идут по три в ряд на десктопе.

Подпись читается как «название → издание → роль». На телефоне до 640 px избранные сохраняют
полноразмерную обложку и всю роль; остальные показываются компактным списком, где название
и роль занимают по одной строке с многоточием. Полная роль доступна в окне просмотра.
Те же поля используются в подписи поверх слайда и в ленте вертикальных видео.

Карусель листается стрелками, точками, клавишами ←/→ и свайпом. Автопрокрутка — каждые 6 секунд;
она приостанавливается при наведении, фокусе, касании, открытом плеере и в скрытой вкладке.
Есть кнопка ручной паузы. При `prefers-reduced-motion` слайды меняются мгновенно без автопрокрутки.

## Как добавить вертикальное видео

Секция «Вертикальные» собирается из тех же `videos.json` — из записей с полем `"vertical": true`.
Пока таких записей нет, секция на странице не выводится вообще (в разметке она помечена `hidden`).

```json
{
  "id": 9,
  "vertical": true,
  "short": "Шортс: манипуляции в продажах",
  "title": "Полное название — показывается в окне просмотра",
  "description": "Нарезка для Shorts и Reels",
  "url": "https://www.youtube.com/shorts/dQw4w9WgXcQ",
  "thumbnail": "covers/short1.avif",
  "platform": "youtube"
}
```

- Поле `short` — подпись под карточкой, `title` — заголовок в окне. Если `short` нет, берется `title`.
- Ссылку можно вставлять как обычную страницу: `youtube.com/shorts/ID`, `youtu.be/ID`, `watch?v=ID`,
  `vk.com/clip-123_456`, `vkvideo.ru/video-123_456`, `vk.com/video-123_456`. Скрипт сам превратит ее в embed
  (`embed/ID`, `clip_ext.php`, `video_ext.php`). Готовые embed-ссылки тоже принимаются как есть.
- Обложку берите вертикальную, 9:16 (`covers/*.avif`). Горизонтальный кадр обрежется по центру, и текст на нем порежется.
  Если `thumbnail` пустой, подставится темная заглушка 9:16.
- Карточки идут лентой 9:16 с горизонтальной прокруткой и снапом: на десктопе 4 штуки в ряд (268 px), на мобильном 1.5 карточки.
- Вертикальные записи не попадают в сетку «Проекты» и в витрину первого экрана — она всегда горизонтальная 16:9.
- Обложки вертикальных лежат в `covers/short1.avif` … `covers/short7.avif` (720×1280 для YouTube, 540×960 для клипов VK).
- Важно: клипы VK не встраиваются на страницу, открытую по IP-адресу — нужен домен (GitHub Pages подходит).

## Как посмотреть локально

Открывать `index.html` двойным кликом нельзя — браузер не отдаст `videos.json`
из-за ограничений на файловые ссылки, и портфолио останется пустым. Нужен локальный сервер:

```bash
cd D:/vizitka
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Что где

| Файл | Назначение |
|---|---|
| `index.html` | разметка: первый экран, проекты, вертикальные, контакты, футер, модалка |
| `style.css` | токены (цвета, радиусы, типографика) в самом начале файла |
| `script.js` | загрузка проектов, витрина, модалка с плеером, контакты, год в футере |
| `videos.json` | список проектов и вертикальных видео |
| `covers/` | обложки 16:9 |
| `og.png` | превью 1280×720 для Telegram и соцсетей |
| `favicon.svg` | иконка сайта |

Тема монохромная: акцентного цвета нет, `--accent` — это белый `#f2f2f3` (белая кнопка, активная точка витрины, разделитель ролей).
Вернуть цвет — поменять два токена в `:root`: `--accent` и `--accent-line`.
Там же шкала типографики: 12 / 14 / 16 / 20 / 28 / 40 / 72 (`--fs-xs` … `--fs-2xl`).
Все размеры на странице берутся из этих токенов — произвольных кеглей в файле нет, новые не заводить.

## Контакты

Адреса собираются в `script.js` (объект `CONTACTS`) — в разметке нет ни `mailto:`, ни `t.me`,
чтобы простые парсеры не выдирали адреса из HTML.

Кнопка «Почта» не открывает почтовый клиент, а копирует адрес в буфер и показывает тост
«Адрес скопирован». Если буфер недоступен (старый браузер, небезопасный контекст), сработает
запасной путь через `execCommand`, а при полном отказе — переход по `mailto:`.
Тост — `#toast` в `index.html`, стили `.toast` / `.toast.is-visible`, таймер 2,4 с.

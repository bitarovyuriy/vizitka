# Визитка Юрия Битарова

Статичный сайт-портфолио: `index.html` + `style.css` + `script.js` + `videos.json`.
Хостинг — GitHub Pages: https://bitarovyuriy.github.io/vizitka/

## Как добавить или изменить работу

Все работы лежат в `videos.json` — обычный список, порядок в файле = порядок на сайте.
Витрина в первом экране показывает те же работы по кругу.

```json
{
  "id": 9,
  "short": "Forbes: короткое название для карточки",
  "title": "Полное название видео — показывается в модалке",
  "description": "Одна строка: что именно делал (монтаж, цвет, графика)",
  "url": "https://www.youtube.com/embed/XXXXXXXXXXX",
  "thumbnail": "covers/имя-файла.avif",
  "platform": "youtube"
}
```

- `short` — до ~30 знаков, иначе обрежется в карточке.
- `description` — до ~60 знаков (в карточке две строки, на телефоне не показывается).
- `url` — обязательно ссылка на **embed**-версию: у YouTube это `youtube.com/embed/ID`,
  у VK — `vkvideo.ru/video_ext.php?...`. Обычная ссылка на страницу видео не подойдет.
- `thumbnail` — файл из папки `covers/`, лучше 1280×720 (16:9).
- `platform` — `youtube`, `vk` или `vimeo`: от этого зависит бейдж и параметры плеера.

## Как посмотреть локально

Открывать `index.html` двойным кликом нельзя — браузер не отдаст `videos.json`
из-за ограничений на файловые ссылки, и портфолио останется пустым. Нужен локальный сервер:

```bash
cd D:/vizitka
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Что где

| Файл | Назначение |
|---|---|
| `index.html` | разметка: hero, о себе, работы, контакты, футер, модалка |
| `style.css` | токены (цвета, радиусы, типографика) в самом начале файла |
| `script.js` | загрузка работ, витрина, модалка с плеером, год в футере |
| `videos.json` | список работ |
| `covers/` | обложки 16:9 |
| `og.png` | превью 1280×720 для Telegram и соцсетей |
| `favicon.svg` | иконка сайта |

Цвета и радиусы меняются в блоке `:root` в начале `style.css` — акцент сейчас `--accent: #ff5c1a`.
Там же шкала типографики: 12 / 14 / 16 / 20 / 28 / 40 / 72 (`--fs-xs` … `--fs-2xl`).
Все размеры на странице берутся из этих токенов — произвольных кеглей в файле нет, новые не заводить.
